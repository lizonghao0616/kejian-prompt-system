# 03 · 对比框架与钩子

两大流派的本质区别，以及从中提炼出的黑话、核心命题、钩子规律。

---

## 一句话总结

- OpenClaw = 把「连接一切」做到极致的**平台**（网关 + 多 Agent 编排）
- Hermes = 把「越用越聪明」做到极致的**运行时**（自学习单/多 Agent）

---

## 核心对比表

| 维度 | OpenClaw（龙虾） | Hermes Agent（爱马仕） |
|---|---|---|
| 核心定位 | 网关 + 多 Agent 编排平台 | 自学习单/多 Agent 运行时 |
| 核心机制 | 配置驱动：人写技能，它调用 | 学习驱动：AI 自己写技能、改技能 |
| 记忆能力 | 金鱼记忆，会话即失忆 | 大象记忆，跨会话长期记忆 |
| 技能系统 | 人工编写，ClawHub 分发（13000+） | Agent 自主生成+迭代（118+） |
| 集成能力 | 极强（50+ 平台） | 中等（15+ 平台） |
| 部署难度 | 极易，<30 分钟 | 稍高，2-4 小时 |
| Token 消耗 | 较高（一次 10 万） | 较低（OpenClaw 的 1/20） |
| 安全性 | 高风险操作直接执行 | 敏感操作前主动确认 |
| 社区规模 | 更大更成熟（4.6 倍于 Hermes） | 增长极快 |

---

## 选型决策（适用场景建议）

**选 OpenClaw，如果你：**
- 需要连接大量聊天工具（微信/Telegram/Slack）和企业系统
- 追求可预测性、强控制、审计（团队/安全敏感）
- 希望开箱即用大量现成技能
- 需要多 Agent 协同、复杂路由

**选 Hermes，如果你：**
- 想要越用越懂你的私人 AI 伙伴
- 重复性工作多（编码/文档/工作流），希望 Agent 自己沉淀技能
- 追求本地/低成本部署
- 喜欢「放手」让 AI 自主完成

---

## 黑话体系（钩子金矿）

| 黑话 | 含义 | 钩子价值 |
|---|---|---|
| 养虾 | 部署/使用 OpenClaw | 圈层身份认同 |
| 养马 | 部署/使用 Hermes | 同上 |
| 龙虾 / 爱马仕 | 两款产品的昵称 | 记忆锚点 |
| **养虾不如养马** | 社区叙事：Hermes 技术全面超越 OpenClaw | 最强传播钩子 |

> 「养虾不如养马」是当下最火黑话。但两者不是取代关系，而是共同构成数字生产力「团队」：
> 重度用户常两者一起用——OpenClaw 做网关/编排层，Hermes 做深度执行/学习层。

---

## 核心命题提炼（不是 A 而是 B）

| 维度 | 不是 A | 而是 B |
|---|---|---|
| 产品本质 | 会说不会动的顾问（ChatGPT） | 能思考更能动手的数字员工（Agent） |
| 交互范式 | 一个 prompt、一个聊天框（复制 Google） | 走向「行动」 |
| OpenClaw | 纸上谈兵的军师 | 真能动手干活的员工 |
| Hermes | 用完就丢的工具 | 与你共同成长、记住什么有效的伙伴 |

---

## 钩子规律（Agent 域）

1. **动物隐喻 + 黑话**（龙虾/马/养虾/养马）——圈层黑话自带传播性。
2. **反常识否定**（「不是顾问，是数字员工」「养虾不如养马」）——最强钩子公式。
3. **对比数字锚定**（25 万 vs 10 万星 / 50+ vs 15+ 平台 / 1/20 Token）——数据冲击。
4. **身体隐喻类比**（大脑=脑子 / 眼睛=眼睛 / 手脚=手脚）——把抽象产品讲成器官。
5. **记忆隐喻**（金鱼记忆 vs 大象记忆）——用动物记忆体量化差异。
