# 04 · 课程 → 课件生产流水线（核心）

把任意一个 AI Agent 选题，转成你风格的 24 页课件。五步走 + 一键提示词 + 样例。

---

## 流水线五步

```
选题（产品 / 概念 / 对比）
  │ Step 1  定课程（全景入门 / 单产品实操 / 协同 / 进阶）
  │ Step 2  提炼核心命题（不是A而是B，落点「从对话到行动」）
  │ Step 3  六模块映射（AI Agent 专属骨架）
  │ Step 4  拆论据（从对比/数字/黑话/案例里拆 3–6 条）
  ▼ Step 5  套 24 页模板（第一课骨架，见下）
```

---

## AI Agent 专属六模块骨架（24 页）

> 注意：这是「产品认知类」骨架，与内核进化/生命重启的「机制/行为类」骨架不同。
> 共享「认知重置」和「闭环收束」两个端点，中间四模块换成「产品全景/流行背景/争议与边界/入门指南」。

| 模块 | 页数 | 内容 |
|---|---|---|
| 一、认知重置 | 1-4 | 封面 / 误区(AI=聊天机器人) / 什么是 Agent(对话→行动) / 爆发背景 |
| 二、产品全景 | 5-9 | 产品地图(办公vs编程) / OpenClaw 全景 / Hermes 全景 / 核心对比 / 养虾不如养马 |
| 三、流行背景 | 10-13 | 为什么 2026 突然火 / GitHub 星标风暴 / 破圈 / 商业机会 |
| 四、争议与边界 | 14-17 | 安全风险 / Token 成本 / 开源 vs 商业化 / 课程定位与边界 |
| 五、入门指南 | 18-21 | 选型决策树 / OpenClaw 快速体验 / Hermes 快速体验 / 课程地图 |
| 六、闭环收束 | 22-24 | 核心 takeaways / 下一课预告 / 封底 |

---

## Step 1 · 定课程

| 课程类型 | 判断 | 骨架落点 |
|---|---|---|
| 全景入门 | 讲「是什么 + 怎么选」（第一课） | 六模块全用 |
| 单产品实操 | 讲「某产品从零到一」（第二/三课） | 偏「产品全景」+「入门指南」 |
| 协同实战 | 讲「多 Agent 组合」（第四课） | 偏「产品全景」+「入门指南」 |
| 进阶跃迁 | 讲「编程 Agent/工具链」（第五课） | 偏「流行背景」+「争议边界」 |

---

## Step 2 · 提炼核心命题

套「不是A而是B」模板，落点统一在「从对话到行动」：

```
不是 [传统工具/误区]，而是 [Agent 的正确框架]。
```

| 选题 | 核心命题 |
|---|---|
| AI Agent 全景 | 不是「会说话的顾问」，而是「能动手的数字员工」 |
| OpenClaw | 不是「纸上谈兵的军师」，而是「真能干活」 |
| Hermes | 不是「用完就丢的工具」，而是「越用越懂你」 |
| 双 Agent 协同 | 不是「二选一」，而是「网关+执行层的团队」 |

---

## Step 3 · 六模块映射

把选题内容塞进 AI Agent 专属六模块（见上表）。

---

## Step 4 · 拆论据

从 Agent 素材里拆 3–6 条论据：

- **对比数字** → 一条「数据锚定」论据（25万 vs 10万 / 1/20 Token）
- **黑话/隐喻** → 一条「类比解释」论据（龙虾/马 / 金鱼 vs 大象记忆）
- **真实案例** → 一条「场景落地」论据（咖啡下单 / 3小时→8分钟）
- **边界/风险** → 一条「安全边界」论据（Token 成本 / 权限风险）

## 一键提示词（Agent 选题 → 完整 24 页）

```
你是成熟讲师，风格克制、诚实、去神化。请把一个 AI Agent 选题扩展成完整 24 页课件。

【输入】
- 选题名称：{{选题，如：AI Agent 全景入门}}
- 核心命题：{{不是A而是B，如：不是顾问，而是数字员工}}
- 课程类型：{{全景入门 / 单产品实操 / 协同实战 / 进阶跃迁}}

【第一步：定骨架】
- 全景入门 → 六模块全用（认知重置/产品全景/流行背景/争议与边界/入门指南/闭环）
- 单产品实操 → 偏产品全景 + 入门指南
- 协同/进阶 → 偏流行背景 + 争议边界

【第二步：写核心命题】
提炼一句「不是A而是B」，作为第 3 页核心命题，第 23 页呼应。

【第三步：六模块映射 + 24 页】
按本文件「AI Agent 专属六模块骨架」逐页写，每页格式：
[SYSTEM_TAG] + 主标题(≤15字) + 副标题 + 正文(3-5要点/短流程) + 底部总结(金句)

【第四步：论据拆解】
从对比数字/黑话隐喻/真实案例/边界风险里拆 3–6 条论据，穿插进正文。

【铁律】诚实先于震撼 / 边界先于方案 / 去神化 / 每页150-250字。
第 16 页（争议与边界）必须讲安全风险与 Token 成本，第 24 页封底。
封面副题 = 核心命题；封面加一行 > INITIALIZING AGENT_SYSTEM [OK]。
按第 1–24 页顺序输出，每页以「===== 第N页 =====」开头。直接输出文案。
```

## 样例（第一课 封面）

**输入**：选题「AI Agent 全景入门」，命题「不是会说话的顾问，而是能动手的数字员工」。

**第 1 页 封面**
```
[ SYSTEM_BOOT ]
AI Agent 全景入门
从「对话」到「行动」
不是会说话的顾问，而是能动手的数字员工
> INITIALIZING AGENT_SYSTEM [OK]
AI AGENT 01
```

**第 2 页 误区（MYTH_RESET）**
```
[ MYTH_RESET ]
先关掉一个误区
「AI 就是聊天机器人」——这个框架会挡住你看清 2026 年的 AI
AI ≠ 聊天框
真正的智能，正在从「说」走向「做」
```

**第 3 页 核心命题（CORE_MODEL）**
```
[ CORE_MODEL ]
本课的核心命题
不是「会说话的顾问」，而是「能思考、更能动手的数字员工」
从对话到行动
```

（第 4–24 页按「AI Agent 专属六模块骨架」继续）
