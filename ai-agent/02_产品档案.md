# 02 · 产品档案（素材库）

三大类产品：面向普通用户的办公 Agent（OpenClaw、Hermes）+ 面向专业开发者的 Coding Agent。

---

## OpenClaw（「龙虾」/「虾」）—— 第一代实干型 AI Agent

### 基本档案
| 项目 | 信息 |
|---|---|
| 全称 | OpenClaw（曾用名 Clawdbot、Moltbot） |
| 开发者 | 奥地利开发者 Peter Steinberger（PSPDFKit 创始人） |
| 发布时间 | 2025-11 个人项目发起，2026-01 正式定名 |
| 开源协议 | MIT |
| GitHub 热度 | 上线不到五个月 25 万星标，周下载量 150 万次 |
| 昵称 | 「龙虾」「小龙虾」（图标形似红色龙虾） |
| 圈内黑话 | 部署/调试/运维全过程叫「养虾」 |

### 核心定位
开源 AI 智能体框架：把 AI 从「纸上谈兵的军师」变成「真能动手干活的员工」。
工信部官方定义：通过整合多渠道通信能力与 LLM，构建具备持久记忆、主动执行能力的定制化 AI 助手，可本地私有化部署。

### 三层结构（给大模型配「手脚」）
| 层级 | 功能 | 类比 |
|---|---|---|
| 大脑 | 大语言模型——理解语义、规划任务、拆解指令 | 会思考的脑子 |
| 眼睛 | 视觉模型——看懂屏幕、识别按钮位置 | 能看见的眼睛 |
| 手脚 | 各类工具——控制鼠标、模拟键盘、执行操作 | 能干活的手脚 |

### 核心能力
- 本地文件管理：直接读写本地文件系统
- 全网信息感知：搜索和获取互联网信息
- 多 Agent 协同
- 定时任务自动化（Cron 表达式）
- 多模态信息处理（文本/PDF/表格/图片）
- 工具集成（调用外部工具和 API）

### 应用场景
- 日常办公：定时爬取新闻、生成会议纪要、批量处理文档表格
- 个人效率：管理日程待办、整理下载文件夹、处理图片视频
- 真实案例：自动下单咖啡 / 睡觉时完成代码修改部署 / 生物医药企业飞书处理实验数据（3 小时→8 分钟，成本降 70%）

### 优劣势
- 优势：生态庞大（50+ 平台）/ 上手极快（<30 分钟）/ 技能丰富（ClawHub 13000+）/ 控制性强（适合团队）
- 劣势：金鱼记忆（会话即失忆）/ 无法自主进化 / Token 消耗高（一次 10 万）/ 安全风险

## Hermes Agent（「爱马仕」/「马」）—— 第二代自进化 AI Agent

### 基本档案
| 项目 | 信息 |
|---|---|
| 全称 | Hermes Agent |
| 开发者 | Nous Research（Hermes、Nomos 开源模型开发者） |
| 发布时间 | 2026-02-25 正式开源 |
| 开源协议 | MIT |
| GitHub 热度 | 迅速超 10 万 Star |
| 昵称 | 「爱马仕」「马」（对标奢侈品牌 Hermès） |
| 圈内黑话 | 搭建/调教/持续使用叫「养马」 |

### 核心定位
官方定位「The agent that grows with you」（与你共同成长的智能体）。
解决的核心问题：别人只谈 Agent 能做什么，没人注意 Agent 用完不留下什么——Hermes 能记住「什么方法有效」。

### 核心能力：自我进化学习闭环
```
执行任务 → 评估结果 → 提取模式 → 写入 Skill → 下次检索复用
```
触发自动生成 Skill 的条件（满足任一）：工具调用 >5 次 / 中途出错自己修复 / 用户纠正 / 走了不明显但有效的路径。

### 三层记忆架构
| 记忆层 | 功能 |
|---|---|
| Session Memory | 当前对话的短期记忆 |
| Persistent Memory | 跨会话的事实与偏好 |
| Skill Memory | 解决方案模式库 |

配合 FTS5 全文检索 + LLM 摘要实现长期记忆召回。

### 核心能力清单
- 自我进化：从经验沉淀技能、使用中持续优化
- 跨会话记忆：记住写作风格、代码习惯、踩过的坑
- 多平台接入：15+ 平台（Telegram/Discord/Slack/WhatsApp/Signal/飞书/微信等）
- 内置 Cron 自动化（自然语言设定时任务）
- 子代理并行（Spawn 隔离子 Agent）
- 低成本部署（5 美元 VPS）
- 内置 47 个工具（8 大类：网络搜索/终端执行/浏览器自动化/AI 绘图等）

### 优劣势
- 优势：自我进化 / 长期记忆（大象记忆）/ Token 精打细算（OpenClaw 的 1/20，懒加载）/ 安全确认机制 / 低成本
- 劣势：集成较弱（15+，不到 OpenClaw 1/3）/ 门槛稍高（2-4 小时）/ 生态不成熟（社区约 OpenClaw 1/4.6）
