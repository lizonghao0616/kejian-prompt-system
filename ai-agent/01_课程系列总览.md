## 各课明细

### 第一课：AI Agent 全景入门（本课）
- 什么是 AI Agent？—— 从「对话」到「行动」的范式转变
- 主流 Agent 产品全景图
- OpenClaw vs Hermes Agent：两大流派对比
- 「养虾」与「养马」：圈内黑话解析
- 课程地图预告

### 第二课：OpenClaw 从零到一
- OpenClaw 是什么？为什么火？
- 本地部署 vs 云端部署（阿里云一键部署）
- 核心功能实操：文件管理、全网搜索、定时任务
- 真实场景演练：自动生成日报、管理日程

### 第三课：Hermes Agent 从零到一
- Hermes Agent 是什么？为什么说它「自我进化」？
- 部署实操（30元人民币 VPS 方案）
- 核心功能实操：记忆系统、技能自动生成
- 真实场景演练：让 Agent「越用越懂你」

### 第四课：双 Agent 协同实战
- OpenClaw 做网关 + Hermes 做执行层
- 跨平台任务编排
- 真实工作流搭建

### 第五课：进阶——Coding Agent 与开发工具链
- Claude Code / Codex / OpenCode 入门
- OpenRouter 统一模型切换
- CC Switch 一站式管理
- 从「办公 Agent」到「编程 Agent」的能力跃迁
