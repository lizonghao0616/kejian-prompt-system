# 02 · 两域 → 两条品牌线的映射

111 个选题天然分成两大域，正好对应课件体系里的两条品牌线。这是整套整合的「总开关」——**先定品牌线，后续骨架、命题落点、六模块映射全都跟着定。**

---

## 总映射

| 选题域 | 选题数 | 品牌线 | 核心命题落点 | 地基工程重点 |
|---|---|---|---|---|
| 通用认知域 | 71 | **内核进化** | 重训认知 + 行为 | 睡眠/压力/代谢/运动（服务大脑） |
| 高阶生化域 | 40 | **生命重启** | 重建身体地基 + 系统调节 | 进食/血糖/炎症/肌肉/线粒体 |

---

## 判断规则：一个选题归哪条线？

按「**落点在脑还是落在身**」判断：

- 落点在**认知·行为·动机·注意力·情绪·记忆**（讲大脑怎么想、怎么做）→ **内核进化**。
- 落点在**分子·代谢·内分泌·激素·能量**（讲身体怎么运转、某物质怎么调）→ **生命重启**。

| 信号 | 品牌线 |
|---|---|
| 选题名含「学习/记忆/注意力/动机/拖延/心流/成瘾/冥想」 | 内核进化 |
| 选题名含「多巴胺/皮质醇/血清素/激素/受体/通路」但讲「行为改变」 | 内核进化（认知角度） |
| 选题名含「线粒体/ETC/NAD+/ROS/HPA轴/内分泌/代谢/酶/受体亚型」 | 生命重启 |
| 选题名含某分子且讲「机制细节、通路、半衰期、受体亚型」 | 生命重启 |

> 边界案例：「多巴胺」在通用认知域（#13–22）讲行为动机 → 内核进化；在高阶生化域（#80–86）讲通路/受体/调控 → 生命重启。**同一个分子，取决于你讲「行为」还是「机制」。**

---

## 两域各自的「核心命题」模板

### 内核进化（通用认知域）

命题落点 = **「不是意志力/资源问题，是反馈结构/学习机制问题」**。

模板：
```
不是 [流行误区：你缺X/你不够自律]，而是 [正确框架：大脑的反馈结构/学习算法在重训你的偏好]。
```

| 选题 | 核心命题（不是A而是B） |
|---|---|
| 多巴胺（#13） | 不是「多巴胺让你快乐」，而是「它在重训你想要什么」 |
| 拖延（#20） | 不是「你懒」，而是「大脑对未来奖励打了折现」 |
| ADHD（#39） | 不是「不专注」，而是「注意力无法定向（缺高亮标签）」 |
| 压力（#43） | 不是「皮质醇是坏激素」，而是「它该下班却没下班」 |

### 生命重启（高阶生化域）

命题落点 = **「不是单一补剂/排毒，而是系统层面的能量/代谢重装」**。

模板：
```
不是 [流行误区：补X/排X就能修]，而是 [正确框架：这是一条通路/一个系统，要按顺序重建]。
```

| 选题 | 核心命题（不是A而是B） |
|---|---|
| 线粒体（#72） | 不是「吃补剂发电」，而是「重装能量系统（拆旧厂建新厂）」 |
| 皮质醇（#87） | 不是「降皮质醇」，而是「重建HPA三级指令链的节律」 |
| 血清素（#97） | 不是「快乐素」，而是「满足素（我够了）」 |
| 乳酸（#78） | 不是「代谢废物」，而是「线粒体的备用燃料」 |

## 两域各自的「六模块」落点差异

| 六模块 | 内核进化（认知域） | 生命重启（生化域） |
|---|---|---|
| 1 认知重置 | 关「意志力/自律」误区 | 关「补剂万能/排毒」误区 |
| 2 系统拆解 | 脑区通路、学习算法 | 分子通路、代谢链、HPA轴 |
| 3 地基工程 | 睡眠/压力/代谢/运动（服务大脑） | 进食/血糖/炎症/线粒体/肌肉 |
| 4 即时工具 | 环境设计、拦截、启动、呼吸 | 冷暴露、光照、运动时机、进食窗口 |
| 5 心智整合 | 古典心智（旁观冲动） | 中西医对照、身体觉察（内感受） |
| 6 闭环收束 | 7天行为重训 | 7天代谢/节律实验 |

## 同一主题的「双线」示范：多巴胺

「多巴胺」这个主题，两条线都能做，但完全不同：

| 维度 | 内核进化版（#13–22） | 生命重启版（#80–86） |
|---|---|---|
| 核心命题 | 多巴胺在重训你的价值排序 | 多巴胺是一条可微调的生化流水线 |
| 系统拆解 | 三通路（动机/认知/运动） | D1–D5 受体亚型、合成流水线、半衰期 |
| 地基 | 睡眠/运动/环境线索 | 酪氨酸底物、受体密度、NAD+ |
| 工具 | 90秒拦截、5秒启动、环境设计 | 冷水暴露参数、运动剂量、药物边界 |
| 收束 | 奖励学习重新服务长期目标 | 受体敏感性 + 系统重建 |

**结论**：拿到一个选题，先问「我这次要讲行为，还是讲机制？」——答案决定品牌线，也决定整份课件的骨架。
