# 03 · 一句话钩子规律（从 111 个钩子里提炼）

111 个选题的「一句话钩子」不是随便写的，它们遵循 7 类固定公式。掌握这 7 类，你就能给任何新选题现写钩子。

---

## 7 类钩子公式

### 1. 反常识否定（出现最多，~40%）

**公式**：`X 不是 A，是 B` —— 先否定流行认知，再给正确框架。

| 例子 |
|---|
| 多巴胺不是快乐分子，是欲望分子 |
| 咖啡因不是充电——是拔了低电量报警线 |
| 血清素不是快乐素，是满足素 |
| 乳酸不是废物——是线粒体的备用燃料 |
| 心流不是超级专注——是自我批判系统被关了 |

> 这类钩子 = 课件体系里的「核心命题」，可直接复用。

### 2. 比喻下定义（~20%）

**公式**：`A = B`（一个生活化比喻，把复杂机制一句话说清）。

| 例子 | 本体 → 喻体 |
|---|---|
| 手机=掌上老虎机 | 下拉刷新 → 老虎机按钮 |
| 睡眠=大脑的磁盘碎片整理 | NREM/REM → 整理/卸载 |
| 多巴胺是差值探测器 | 多巴胺 → 探测器 |
| BDNF是脑细胞的高氮复合肥 | BDNF → 肥料 |
| NAD+/NADH比值=细胞的电量百分比 | 比值 → 电量 |
| 蓝斑核=全脑去甲肾上腺素的唯一源头 | 蓝斑核 → 源头 |

### 3. 机制链箭头（~15%）

**公式**：`A → B → C`（三步因果链，制造「原来是一环扣一环」的顿悟）。

| 例子 |
|---|
| DMN抑制→工作记忆重置→物理重置 |
| 热水→血管扩张→核心温15分钟降1℃→睡眠启动 |
| 运动→肌肉分泌鸢尾素→白色脂肪变棕色→开始燃烧热量 |
| 乳酸→去甲肾上腺素→前额叶进攻模式→焦虑被覆盖 |
| CRH→ACTH→皮质醇——三级指令链 |

### 4. 精确参数（~12%）

**公式**：`数字 × 单位 + 具体条件`（精确到可执行，天然有可信度）。

| 例子 |
|---|
| 14℃×1-3min，多巴胺持续高位3小时 |
| 起床90-120分钟后喝咖啡，下午2点前最后一杯、＜400mg |
| 双吸气+长呼气（生理叹气） |
| 盒式(冷静)、4-7-8(入眠)、温姆霍夫(可控压力) |
| 午睡20分钟或90分钟 |

### 5. 借贷/账本隐喻（~8%）

**公式**：把「透支/偿还」讲成财务账本，抽象机制变可感。

| 例子 |
|---|
| 每次峰值后基线掉一截——快乐在借贷 |
| 周末补觉能还本金——利息(炎症因子+皮质醇紊乱)已入账 |
| 大脑对未来奖励打了折现 |
| 轮班工作=每几天手动拔BIOS时钟 |

### 6. 对比数字（~5%）

**公式**：`A 比 B 快/强 N 倍`（用倍数制造反差）。

| 例子 |
|---|
| 海马体回放在间隙暴涨20倍 |
| 先看目录比直接读正文快3倍 |
| 合书复述5分钟＞再看20分钟×1.5 |
| 成瘾者D2密度暴跌40% |

### 7. 时机钩子（~5%）

**公式**：`在某一秒/某一刻，发生关键转折`（制造「就差这一下」的精准感）。

| 例子 |
|---|
| 刚好快忘还没忘的那一秒复习，效率最高 |
| 被批评时皮质醇15秒涨3倍 |
| 下午3点咖啡因暴涨 |
| 每10分钟闭眼10秒 |

---

## 钩子的三条底层原则

1. **反常识优先**：先否定一个流行误区，钩子才有张力。纯陈述（「睡眠很重要」）没有钩子。
2. **能量化就不模糊**：用「20倍/3小时/400mg/90分钟」代替「很多/一会儿/适量」。
3. **一个钩子只讲一个反常识点**：不要在一句话里塞两个转折，否则听众记不住。

---

## 钩子 → 课件三要素的转化

| 钩子类型 | 转成课件的哪部分 |
|---|---|
| 反常识否定 | 核心命题（第 3 页）+ 封面副题 |
| 比喻下定义 | 系统拆解页的「一句话定义」（第 4 页） |
| 机制链箭头 | 正文「要点式」或「流程式」（第 5–6 页） |
| 精确参数 | 即时工具页的具体参数（第 16–19 页） |
| 借贷隐喻 | 副标题 / 底部金句 |
| 对比数字 | 正文里的数据锚定 |
| 时机钩子 | 工具页的「何时做」 |

---

## 给 AI 的钩子指令（可单独复制）

```
为一个选题写「一句话钩子」时，按优先级选这 7 类公式之一：
1 反常识否定（X不是A，是B）→ 优先
2 比喻下定义（A=B，生活化）
3 机制链箭头（A→B→C）
4 精确参数（数字×单位+条件）
5 借贷/账本隐喻
6 对比数字（N倍反差）
7 时机钩子（某一秒发生转折）

要求：反常识优先、能量化不模糊、一句话只讲一个反常识点。
```
