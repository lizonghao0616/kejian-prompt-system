# 04 · 选题 → 课件生产流水线（核心）

把任意一个 Huberman 选题，转成你风格的 24 页课件。五步走，最后附一键提示词和完整样例。

---

## 流水线五步

```
选题（名称 + 钩子）
  │ Step 1  定品牌线（讲行为→内核进化 / 讲机制→生命重启）
  │ Step 2  从钩子提炼核心命题（不是A而是B）
  │ Step 3  六模块映射（每模块放什么）
  │ Step 4  拆论据（从钩子的机制/数字/类比里拆 3–6 条）
  ▼ Step 5  套 24 页模板（见根目录 02_课程架构主体.md）
```

---

## Step 1 · 定品牌线

用 `02_两域映射.md` 的判断规则：

- 落点在**认知·行为·动机·注意力·情绪·记忆** → **内核进化**（通用认知域）。
- 落点在**分子·代谢·内分泌·激素·能量** → **生命重启**（高阶生化域）。

一句话问自己：**这次讲「行为怎么改」，还是「机制怎么转」？**

---

## Step 2 · 从钩子提炼核心命题

钩子里的「反常识否定」往往已经是命题雏形。套模板：

```
不是 [钩子里否定的流行误区]，而是 [钩子里给的正确框架]。
```

| 钩子 | 提炼出的核心命题 |
|---|---|
| 多巴胺不负责爽，它负责想要 | 不是「多巴胺=快乐」，而是「多巴胺在重训你想要什么」 |
| 快乐在借贷 | 不是「越爽越快乐」，而是「每次峰值都在透支基线」 |
| 想动但动不了——缺的是去甲肾上腺素 | 不是「缺多巴胺」，而是「动机与行动是两套系统」 |

---

## Step 3 · 六模块映射

把选题内容塞进六大模块，每模块一个「干什么」：

| 模块 | 内核进化（行为线） | 生命重启（机制线） |
|---|---|---|
| 认知重置 | 关 3 个流行误区 | 关「补剂/排毒」误区 |
| 系统拆解 | 通路/算法 | 分子通路/代谢链 |
| 地基工程 | 睡眠/压力/代谢/运动 | 进食/血糖/炎症/线粒体 |
| 即时工具 | 环境/拦截/启动/呼吸 | 冷暴露/光照/运动时机/进食窗口 |
| 心智整合 | 古典心智旁观 | 中西医对照/内感受 |
| 闭环收束 | 7天行为重训 | 7天代谢节律实验 |

---

## Step 4 · 拆论据

从钩子里拆出 3–6 条论据。钩子的「机制链 / 精确参数 / 对比数字 / 比喻」各拆一条：

- **机制链** → 一条「通路/算法」论据
- **精确参数** → 一条「可执行参数」论据
- **对比数字** → 一条「数据锚定」论据
- **比喻** → 一条「类比解释」论据
- **边界/禁忌** → 一条「安全边界」论据

---

## Step 5 · 套 24 页模板

直接用根目录 `02_课程架构主体.md` 的 24 页职责表 + `00_一键主提示词.md` 的主提示词。下面是**融合了 Huberman 选题映射的一键提示词**。

---

## 一键提示词（选题 → 完整 24 页）

```
你是成熟讲师，风格克制、诚实、去神化。请把一个 Huberman 选题扩展成完整 24 页课件。

【输入】
- 选题名称：{{选题名称，如：多巴胺基线vs峰值：越爽越空虚}}
- 一句话钩子：{{钩子，如：每次峰值后基线掉一截——快乐在借贷}}
- 品牌线：{{内核进化 / 生命重启}}

【第一步：定骨架】
- 若品牌线=内核进化：核心命题落点「不是意志力/资源问题，是反馈结构/学习机制问题」。
- 若品牌线=生命重启：核心命题落点「不是补剂/排毒，是系统层面的能量/代谢重装」。

【第二步：写核心命题】
从钩子里提炼一句「不是A而是B」的命题，作为第 3 页核心命题，并在第 23 页呼应。

【第三步：六模块映射 + 24 页】
按根目录 02_课程架构主体.md 的 24 页职责表逐页写，每页格式：
[SYSTEM_TAG] + 主标题(≤15字) + 副标题 + 正文(3-5要点/短流程) + 底部总结(金句)

【第四步：论据拆解】
从钩子的机制链/参数/数字/比喻里拆 3–6 条论据，穿插进正文。

【铁律】诚实先于震撼 / 边界先于方案 / 行为先于生化 / 去神化 / 重训>排毒 / 每页150-250字。
第 22 页必须是安全边界，第 24 页放参考文献（可隐藏）。
封面副题 = 一句话钩子；封面加一行 > INITIALIZING XXX_SYSTEM [OK]。
按第 1–24 页顺序输出，每页以「===== 第N页 =====」开头。直接输出文案。
```

## 完整样例（第一梯队 #14：多巴胺基线 vs 峰值）

**输入**：选题「多巴胺基线vs峰值：越爽越空虚」，钩子「每次峰值后基线掉一截——快乐在借贷」，品牌线「内核进化」。

### 关键页示范（不写满 24 页，演示方法）

**第 1 页 封面**
```
[ SYSTEM_BOOT ]
内核进化
多巴胺基线 vs 峰值
越爽越空虚
每次峰值后基线掉一截——快乐在借贷
> INITIALIZING REWARD_SYSTEM [OK]
CORE EVOLUTION 01
```

**第 2 页 误区（MYTH_RESET）**
```
[ MYTH_RESET ]
先关掉三个误区
这三个误区会把多巴胺讲成“越多越好”
01 快乐越多越幸福 → 错：峰值越高，基线越低
02 爽是免费午餐 → 错：快乐在借贷，要还
03 多巴胺越高越好 → 错：关键是基线稳定，不是峰值
```

**第 3 页 核心命题（CORE_MODEL）**
```
[ CORE_MODEL ]
本课的核心命题
不是“多巴胺越高越快乐”，而是“每次峰值都在透支你的基线”
多巴胺基线 vs 峰值
```

**第 4 页 正确定义（定义基线/峰值）**
```
[ BASELINE_PEAK ]
多巴胺的两个刻度
它不负责爽，它负责“想要”的强度
基线 → 日常动机水位，决定你平时想不想动
峰值 → 单次刺激的爽感高度，来得越高掉得越狠
一句话：你追的是峰值，赌掉的是基线。
```

**第 5 页 机制（借贷模型）**
```
[ REWARD_LEDGER ]
快乐是一本账
大脑不是感知“爽”，是在算“差额”
爽感 = 峰值 − 基线
每次峰值，基线都会被记账
借贷：峰值越高，之后基线越低，越空虚
金句：快乐不是免费的，它是一笔要还的账。
```

（第 6–21 页按 24 页模板继续：通路拆解 → 高刺激环境 → 测量边界 → 行为仪表盘 → 药理边界 → 咖啡因 → 地基 → 运动 → 饮食 → 环境设计 → 身体调节 → 冲动拦截 → 启动 → 古典心智 → 7天实验）

**第 22 页 安全边界（SAFETY）**
```
[ SAFETY ]
安全边界：这不是医疗方案
越是讲生理机制，越要保护边界
! 处方药 → 不讨论剂量、不做处方建议
! 心理风险 → 严重抑郁/成瘾应寻求专业帮助
! 冷水暴露 → 心血管风险人群避免
课程目标：帮学员理解奖励系统，不替代诊断与治疗。
```

**第 23 页 终极闭环（SYNTHESIS）**
```
[ SYNTHESIS ]
终极闭环：别再追峰值
调控环境、重训行动，让基线回到服务长期目标的位置
SYSTEM RESET
重新定义多巴胺 → 从“快乐分子”到“价值账本”
重新设计环境 → 减少快反馈劫持
重新训练身体 → 睡眠/运动/稳定饮食给基线托底
今晚带走的不是“戒掉快乐”，而是一套让基线稳住的系统。
```

**第 24 页 参考文献（REFERENCES）**
```
[ REFERENCES ]
参考资料与讲课边界
供备课与审核使用，可隐藏不播放
（列出 3–8 条：多巴胺奖赏预测误差 / D2受体下调 / 冷水暴露研究等）
提醒：课件中所有处方药内容仅作科学边界说明，不作为用药建议。
```
