## 核心结论（先记住这三条）

1. **111 个选题天然按品牌线分成两半**：
   - 通用认知域（71 个）→ 走《内核进化》品牌线（认知·行为·动机·睡眠·注意力·记忆）
   - 高阶生化域（40 个）→ 走《生命重启》品牌线（线粒体·多巴胺·皮质醇·激素·分子）

2. **每个选题的「一句话钩子」已经是「不是A而是B」的反常识命题**，可直接当课件的「核心命题」或封面副题。

3. **生成流程**：选题 → 定品牌线 → 从钩子提炼核心命题 → 六模块映射 → 套 24 页模板。详见 `04_选题到课件流水线.md`。
