# 04 · 选题 → 课件生产流水线（核心）

把任意一个 IFS 高阶选题，转成你风格的高阶课件。五步走，最后附一键提示词和完整样例。

---

## 流水线五步

```
选题（名称 + 核心命题）
  │ Step 1  定定位（确认是「内核进化·高阶版」，不是生命重启）
  │ Step 2  从命题提炼「不是A而是B」（母命题的具体化）
  │ Step 3  六模块映射（IFS 高阶版六模块，见下）
  │ Step 4  拆论据（从角色/证据/争议/日常练习里拆 3–6 条）
  ▼ Step 5  套 24 页模板（IFS 高阶版逐页职责表）
```

---

## Step 1 · 定定位

IFS 选题一律走 **《内核进化·高阶版》**：

- 落点在**内在心理系统、自我对话、情绪·认知·行为** → 内核进化，不是生命重启。
- 判断句：**这次讲「心里怎么跟自己对话」，不是「身体怎么运转」。**

---

## Step 2 · 从命题提炼核心命题

IFS 每个选题的「不是A而是B」已经是命题。模板：

```
不是 [「你有病/你没意志力/你失控」的流行误区]，而是 [「某个部分在保护你」的正确框架]。
```

母命题：`你不是一个人，你是一个家庭`。所有高阶选题的命题，都是把母命题落到具体痛点（拖延/成瘾/自我批评/情绪爆发/人际冲突）。

---

## Step 3 · 六模块映射（IFS 高阶版）

| 模块 | 干什么 | 对应页 |
|---|---|---|
| 认知重置 | 关「内心应该只有一个声音」误区，给「部分/真我」新框架 | 1–4 |
| 系统拆解 | 拆三大角色（管理者/消防员/被放逐者）+ 真我 8Cs | 5–9 |
| 流行背景 | 为什么火 + 社交助推 + 去病理化魅力 + 证据 | 10–13 |
| 争议与边界 | 证据不足 + 虚假记忆风险 + 过度简化 + 课程定位 | 14–17 |
| 日常应用 | 识别部分 + 对话管理者 + 对话消防员 + 倾听被放逐者 | 18–21 |
| 闭环与课程导览 | 三大能力 + 课程地图 + 封底 | 22–24 |

> 与标准内核进化六模块的关键差异：**没有「地基工程」（睡眠/运动/饮食）和「即时工具」（环境设计/拦截/启动）**，换成「流行背景 + 争议与边界 + 日常应用」。因为 IFS 是心理框架，不是生理机制——它讲「为什么火、证据到哪、怎么跟自己对话」。

---

## Step 4 · 拆论据

从 IFS 素材里拆 3–6 条论据：

- **角色机制** → 一条「管理者/消防员/被放逐者」论据
- **善意 vs 问题** → 一条「保护者用错方法」论据
- **证据** → 一条「NREPP / 2025 范围综述（27 研究含 2 RCT）」论据
- **争议** → 一条「证据不足 / 虚假记忆风险」边界论据
- **日常练习** → 一条「对话部分」的操作论据
- **去病理化话术** → 一条「症状→信息」类比论据

## 单页固定格式（与根目录一致）

```
[ SYSTEM_TAG ]
主标题（≤15字）
副标题（一句话，承接主标题）
正文（3–5 个短要点 / 一个短流程 / 一张角色表）
底部总结（一句话金句）
```

## 一键提示词（IFS 选题 → 完整 24 页）

```
你是成熟讲师，风格克制、诚实、去神化、去病理化。请把一个 IFS 高阶选题扩展成完整 24 页课件。

【输入】
- 选题名称：{{选题名称，如：与内在批判者和解}}
- 核心命题：{{命题，如：那个说你不够好的声音，其实是想保护你}}
- 品牌系列：内核进化·高阶版

【第一步：定骨架】
用 IFS 高阶版六模块：认知重置(1-4) / 系统拆解(5-9) / 流行背景(10-13) / 争议与边界(14-17) / 日常应用(18-21) / 闭环与课程导览(22-24)。
不用「地基工程 / 即时工具」——IFS 是心理框架，讲「为什么火 + 证据边界 + 怎么跟自己对话」。

【第二步：写核心命题】
从输入命题提炼一句「不是A而是B」，A=「你有病/没意志力/失控」，B=「某个部分在保护你」。第 3 页立论，第 24 页呼应。

【第三步：24 页逐页写】
每页格式：[SYSTEM_TAG] + 主标题(≤15字) + 副标题 + 正文(3-5要点/短流程/角色表) + 底部总结(金句)。
角色必须有「职责 + 常见表现 + 善意 + 问题」成对出现；真我用 8Cs 表。

【第四步：论据拆解】
从角色机制/证据(NREPP+2025范围综述)/争议(证据不足+虚假记忆)/日常练习(对话部分)里拆 3-6 条。

【铁律】诚实先于震撼 / 边界先于方案 / 去神化 / 去病理化 / 每个部分善意与问题成对 / 每页150-250字。
第 14-17 页必须客观呈现争议与边界；第 17 页写「本课程不是心理治疗」；第 21 页标 ⚠️ 安全前提。
封面副题 = 核心命题；封面加一行 > INITIALIZING IFS_SYSTEM [OK]。
按第 1–24 页顺序输出，每页以「===== 第N页 =====」开头。直接输出文案。
```

## 完整样例（首选选题三：内在批判者）

**输入**：选题「与内在批判者和解」，命题「那个说你不够好的声音，其实是想保护你」，品牌系列「内核进化·高阶版」。

### 关键页示范（演示方法，不写满 24 页）

**第 1 页 封面**
```
[ SYSTEM_BOOT ]
内核进化·高阶版
与内在批判者和解
那个说你不够好的声音，其实是想保护你
> 你的内心不是战场，是一个等待被倾听的家庭
> INITIALIZING IFS_SYSTEM [OK]
CORE EVOLUTION · ADVANCED 03
```

**第 2 页 误区（MYTH_RESET）**
```
[ MYTH_RESET ]
先关掉一个误区
「我内心的批评声是敌人，必须打败它」
你心里那个说「你不够好」的声音
不是一个需要消灭的敌人
是一个用旧地图在保护你的管理者
> 你不需要「战胜自己」，你需要「听懂自己」
```

**第 3 页 核心命题（CORE_MODEL）**
```
[ CORE_MODEL ]
本课的核心命题
不是「那个声音在攻击我」，而是「它在用旧方法保护我」
内在批判者 = 管理者的一部分
初衷：用严厉声音督促你「做到完美」以获得认可
问题：它用的是童年形成的旧地图，成年后已不再适用
```

**第 6 页 管理者（MANAGER）**
```
[ MANAGER ]
内在批判者：过时的守门人
它的善意，藏在最刺耳的话里
职责 → 通过自我批判，避免你暴露在失败与拒绝中
策略 → 「你不够好，再努力一点」「再检查三遍，不能出错」
善意 → 它在保护你免受羞耻
问题 → 它用旧地图：童年有效，成年已是枷锁
> 那个说你「不够好」的声音，其实是想保护你
```

**第 19 页 与管理者对话（TALK_MANAGER）**
```
[ TALK_MANAGER ]
日常练习：与你的批判者对话
当「你不够好」的声音响起时
暂停 → 停下手头的事，做三次深呼吸
识别 → 「我注意到有一个『管理者』部分正在工作」
好奇 → 「你在担心什么？你想保护我免受什么？」
感谢 → 「谢谢你努力保护我，我看到你了」
协商 → 「我们现在可以换一种方式吗？不用这么用力」
> 批判者不需要被消灭，它需要被看见、被感谢、被重新分配任务
```

**第 17 页 课程定位（COURSE_SCOPE）**
```
[ COURSE_SCOPE ]
本课程的定位与边界
越是讲内在探索，越要清楚保护边界
✅ 是：自我成长与认知升级、理解内在冲突、自我觉察框架
❌ 不是：心理治疗、创伤治疗替代、诊断、独自处理深层创伤
提醒 → 持续情绪低落或功能受损，请寻求专业评估
> 越是温柔的疗法，越需要严格的边界
```

**第 24 页 封底（CLOSING）**
```
[ CLOSING ]
你不是一个人，你是一个家庭
你的内心有追求完美的管理者
有拼命灭火的消防员
有被关在地下室的受伤小孩
也有平静、好奇、慈悲的真我
它们都不是你的敌人，它们都是你的一部分
> 进化不是偶然，而是设计的结果
```
