## 核心结论（先记住这三条）

1. **IFS 属于《内核进化》品牌线，是它的「高阶版」**——不是第三条品牌线，也不归《生命重启》。它讲的是「情绪·认知·行为」的内在心理系统，落点在「重训认知 + 自我对话」，正好接续你多巴胺/皮质醇课件里的「内在冲突 / 压力源头」。

2. **IFS 用一套独立的高阶六模块骨架**（区别于内核进化的标准六模块）：
   - 标准内核进化：认知重置 / 系统拆解 / 地基工程 / 即时工具 / 心智整合 / 闭环收束
   - **IFS 高阶版**：认知重置 / 系统拆解 / 流行背景 / 争议与边界 / 日常应用 / 闭环与课程导览
   - 因为没有「身体地基 / 生理机制」可讲，IFS 把「地基工程 / 即时工具」换成「流行背景 / 争议与边界 / 日常应用」——讲清「为什么火 + 证据边界 + 怎么用」。

3. **核心命题一句话**：`你不是一个人，你是一个家庭`——对应「不是 A 而是 B」的固定命题格式，A=「内心应该只有一个声音」，B=「内心是多个善意部分的家庭系统」。
