# 03 · IFS 钩子规律与核心命题

从 5 个高阶选题 + 第一课里提炼出的 IFS 专属钩子公式与核心命题写法。

---

## 五个核心命题（都是「不是 A 而是 B」）

| 选题 | 核心命题 |
|---|---|
| 内在冲突 | 你不是在和自己的弱点作战，你是在忽略你内在的消防员 |
| 成瘾行为 | 你不是在和成瘾作战，你是在和一个疲惫的消防员谈判 |
| 内在批判者 | 那个说你不够好的声音，其实是想保护你——只是它用的方法已经过时了 |
| 创伤与情绪 | 你的情绪爆发不是「失控」，是你被关在地下室的「被放逐者」在敲门 |
| 人际关系 | 你在不同人面前「像变了一个人」——因为你本来就不是一个人，你是一个家庭 |

> 第一课封面主命题：`你不是一个人，你是一个家庭`——这是 IFS 全系列的「母命题」，其余 5 个命题都是它的具体化。

---

## IFS 专属钩子公式（4 类）

### 1. 去病理化反转（最强，~40%）

**公式**：`问题行为不是「坏」，是「善意的保护」`——把症状翻译成保护。

| 例子 |
|---|
| 拖延不是懒——是管理者在帮你避免失败羞耻 |
| 刷手机不是没意志力——是救火员在帮你逃离焦虑 |
| 暴食不是失控——是消防员在帮你灭火 |
| 自我批评不是敌人——是过时的保护者 |

> 这是 IFS 钩子的灵魂：**先否定「你有病」，再给「你在被保护」的新框架。**

### 2. 命名部分（把抽象情绪拟人化）

**公式**：`那个「X」不是我，是「一个 Y 的部分」`——把情绪从「我」里剥离出来。

| 例子 |
|---|
| 不是「我很焦虑」，是「我注意到有一个焦虑的部分」 |
| 不是「我就是懒惰」，是「我注意到有一个想休息的部分」 |
| 不是「我失控了」，是「我有一个很想逃的部分」 |

> 这种「解融合」话术自带距离感：从「被情绪淹没」切换到「与情绪保持距离」。

### 3. 身体/空间隐喻（把抽象系统讲成器官/房间）

**公式**：`内在系统 = 家庭 / 房子 / 地下室 / 驾驶座`。

| 本体 → 喻体 |
|---|
| 内在部分 → 家庭里的成员 / 员工 |
| 被放逐者 → 被关在地下室的受伤小孩 |
| Self 真我 → 驾驶座上的领导者 |
| 部分冲突 → 一场需要主持的家庭会议 |

### 4. 谈判叙事（对抗 → 协商）

**公式**：`不是「消灭/戒掉」，是「倾听/感谢/协商」`。

| 例子 |
|---|
| 不是打败管理者，是倾听它、感谢它、重新分配任务 |
| 不是戒掉消防员，是给它一个不那么极端的方式 |
| 不是挖出被放逐者，是安全地看见它 |

| 钩子类型 | 转成课件的哪部分 |
|---|---|
| 去病理化反转 | 核心命题（第 3 页）+ 封面副题 |

| 身体/空间隐喻 | 系统拆解页的「一句话定义」+ 角色表 |
| 谈判叙事 | 日常练习页的「步骤」+ 底部金句 |

---

## IFS 钩子的三条底层原则

1. **先否定「病」，再给「保护」**：IFS 钩子必须包含「你没问题」的安慰感，否则就是普通心理学课。
2. **每个部分都要「善意 + 问题」成对出现**：只说善意是鸡汤，只说问题是病理化——IFS 的力度在于「这个保护者用错了方法」。
3. **一句话只反转一个误区**：不要同时讲「不是懒」和「不是没意志力」两个反转，选最戳的那个。

## 给 AI 的钩子指令（可单独复制）

```
为一个 IFS 选题写「一句话钩子」时，按优先级选这 4 类公式之一：
1 去病理化反转（问题行为不是坏，是善意的保护）→ 优先
2 命名部分（那个X不是我，是一个Y的部分）
3 身体/空间隐喻（内在系统=家庭/地下室/驾驶座）
4 谈判叙事（不是消灭，是倾听/感谢/协商）

要求：先否定「病」再给「保护」；每个部分善意与问题成对出现；一句话只反转一个误区。
```

## 与根目录 7 类钩子公式的关系

IFS 的「去病理化反转」本质是根目录 `huberman/03_钩子规律.md` 里「反常识否定」在心理学域的特化版——但多了一层「安慰感」：IFS 的反转不是为了制造反差冲击，而是为了卸下「我有病」的重担。因此 IFS 钩子的落点是「疗愈」，不是「颠覆」。
