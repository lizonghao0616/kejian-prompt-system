# 课件提示词体系（Kejian Prompt System）

把「内核进化」「生命重启」两个课程系列的课件写法，抽象成一套可复用的**提示词体系**。

只要给 AI 一个**主题 + 几个论据**，配合本仓库的提示词，就能生成一份与源文件风格、体系、叙事结构高度一致的完整 PPTX 文案。

---

## 这套体系是什么

它不是「随便写点漂亮的课件文案」，而是从真实源文件里逆向提取出的**底层规律**：

| 维度 | 规律 |
|---|---|
| 叙事弧线 | 三段式：抛出（20%）→ 探讨（35%）→ 解决（45%） |
| 模块骨架 | 六大模块：认知重置 / 系统拆解 / 地基工程 / 即时工具 / 心智整合 / 闭环收束 |
| 单页格式 | `[ SYSTEM_TAG ] + 主标题(≤15字) + 副标题 + 正文 + 底部总结` |
| 文案铁律 | 诚实先于震撼 / 边界先于方案 / 行为先于生化 / 去神化 / 重训>排毒 |
| 品牌标题 | 情绪认知→《内核进化》；代谢内分泌→《生命重启》 |

完整规律见各分文件，底层证据见 `06_源文件结构解析.md`。

## 最快上手

1. 打开 `00_一键主提示词.md`，复制整段提示词。
2. 把 `{{主题}}`、`{{品牌系列}}`、`{{目标受众}}`、`{{核心命题}}`、`{{论据}}` 替换成你的内容。
3. 丢给 Claude / ChatGPT 等，得到一份 24 页的完整课件文案（含每页 SYSTEM_TAG、主标题、副标题、正文、底部总结）。
4. 若要生成可编辑的 PPTX 文件，再把文案 + `05_PPTX模板规格.md` 一起给 AI 生成模板。

---

## 两条品牌线的差异

- **《内核进化》**（情绪·认知·行为类主题）——落点偏「认知重置 + 行为重训」。
- **《生命重启》**（代谢·内分泌·情绪类主题）——落点偏「身体地基 + 系统调节」。

两者共用同一套骨架，只是「核心命题」和「论据」的落点不同。选择哪条线，由主题所属领域决定。
